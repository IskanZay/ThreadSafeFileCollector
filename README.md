# Описание
Я использовал map для хранения чанков. map потому что он хранит данные в отсортированном виде в виде дерева 
и можно найти следующий и предыдущие элементы за O(logn), что обеспечивает эффективность. У меня есть два уровня мьютекса, один для добавления в хеш-таблицу, 
другой для каждого файла. То есть у каждого файла свой мьютекс, чтобы разные файлы обрабатывались в разных потоках. Один мьютекс на файл 
всё равно позволяет писать нескольким потокам в один файл как написано в задании, хоть и по блокировке, но зато корректно(вроде). Покрыл все основные сценарии
тестами на gtest, в том числе и многопоточные тесты.
